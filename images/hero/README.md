# Hero slideshow images

The homepage slideshow currently references owner-supplied watch photographs in `dress&co img/`; it reuses the source files and does not require copies in this folder. To add, remove or replace slides, edit the `heroPhotos` list in `script.js` and keep the first HTML slide source in `index.html` aligned with the first item for the initial paint.

If you add optimized replacement photographs here, use descriptive names such as `hero-watch-01.webp` and update both references. Use confirmed DREESO & CO imagery only, and do not use a photograph to imply unconfirmed product availability, price or specifications.
